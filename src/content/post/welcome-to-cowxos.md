## Introducing CowxOS

**CowxOS** is a performance-first Linux distribution built on Arch Linux. We ship every package optimized for modern CPUs, delivering measurable speed improvements for everyday computing, development, and gaming.

### What Makes CowxOS Different

- **CPU-Optimized Packages**: Compiled with x86-64-v3, x86-64-v4, and Zen4 instruction sets, plus LTO and PGO optimizations.
- **Custom Kernel**: A tuned kernel with multiple scheduler options (BORE, EEVDF, sched-ext, BMQ, RT).
- **Multiple Desktop Environments**: Choose from KDE Plasma, GNOME, XFCE, Hyprland, and more.
- **Simple Installation**: Graphical installer for a guided setup, or CLI installer for full control.

### Getting Started

1. Download the latest ISO from our [download page](/download).
2. Create a bootable USB drive.
3. Boot and follow the installation wizard.
